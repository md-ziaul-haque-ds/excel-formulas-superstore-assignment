# Excel Formulas and Techniques: Superstore Practice Workbook

A formula-driven Excel workbook built on the Superstore sample dataset. It covers 44 topics across 12 sections, from basic functions to pivot tables, lookups and macros. Open the **Index** sheet first: it links to every topic sheet.

## What is covered

| Section | Topics |
|---|---|
| 1. Basics | SUM, MAX, MIN, SMALL, LARGE, INDEX-MATCH, TRANSPOSE, COUNT / COUNTA / COUNTBLANK, status bar, growth % and POWER |
| 2. Formatting | Cell and number formats, wrap text and alignment, Format Painter |
| 3. Sort and filter | Sorting numbers, dates and text, sorting by colour, multi-level sort |
| 4. Dates | DATEDIF, date duration with timestamps, DATE, YEAR, MONTH, DAY, TODAY, EOMONTH |
| 5. Logical functions | IF, AND, OR, nested logic, IFERROR |
| 6. Data cleaning | Remove duplicates, TRIM, LEN, LEFT, RIGHT, MID, UPPER, PROPER, LOWER, VALUE, SEARCH vs FIND, Go To Special, Text to Columns, CONCATENATE, SUBSTITUTE, Find and Replace |
| 7. Pivot tables | Basics, grouping, dates and blanks, custom grouping |
| 8. Lookups | VLOOKUP (exact and approximate), VLOOKUP vs HLOOKUP |
| 9. Conditional aggregation | COUNTIF, SUMIF, AVERAGEIF, COUNTIFS, SUMIFS |
| 10. Conditional formatting | Colouring cells by condition |
| 11. Report consolidation | 3-D SUM across sheets, Consolidate feature, SUBTOTAL |
| 12. Macros (separate file) | What VBA is, Developer tab, recording and running a macro, VBA workspace, getting VBA code |

## Files
- `Excel_Assignment.xlsx`: Sections 1 to 11, one sheet per topic. The original Superstore sheets (Orders, Returns, People) are included unchanged at the end.
- `Basic_Macros_Exercise.xlsm`: Section 12 (macros). Enable macros to run the recorded example.

## Tools
Microsoft Excel: formulas and functions, pivot tables, conditional formatting, Consolidate, SUBTOTAL, basic VBA macros.

## Data source
Superstore sample dataset (a standard sample dataset used for Excel and BI practice).
